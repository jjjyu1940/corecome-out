Apply this package to jjjyu1940/corecome-out (main):
1. Copy Makefile to repository root.
2. Replace .github/workflows/alpos-x86-iso.yml with the included workflow.
3. Existing kernel/, iso/, and tools/ build input files in this package are snapshots of the matching main-branch paths at packaging time. They are included for reproducibility; the root Makefile and workflow are the intended changes.
4. Run `make`, then `make iso`, then `make test` on Ubuntu 24.04 with the dependencies listed in README-OVERLAY.md.
5. In GitHub Actions, run the workflow manually or push a commit touching the configured paths. Download the `alpos-x86_64-build` artifact after it completes.
