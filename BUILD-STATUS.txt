Build package status
====================

Verified in the authoring sandbox:
- `make` builds kernel/build-x86/alpos-kernel.elf.
- Output is ELF64 for x86-64.
- The Multiboot2 header validator passes.
- The ZIP archive integrity check passes.

The GitHub Actions workflow has been changed so that ISO creation is an
explicit required step (`make iso`) after ELF compilation. It verifies that
kernel/build-x86/alpos.iso exists and is non-empty before proceeding. QEMU
smoke testing is separate and non-blocking, so a QEMU issue cannot prevent
uploading an ISO that was successfully created. The artifact is named
`alpos-x86_64-elf-and-iso`.

Not verified in this sandbox:
- Actual ISO creation, because grub-mkrescue and xorriso are not installed.
- Actual QEMU boot.
- Execution of the workflow on GitHub.

This is a focused overlay/build snapshot, not a full export of the GitHub
repository. Apply its root Makefile, workflow, and tools/image/mkiso.sh to the
repository before expecting GitHub Actions to use these changes.
